# Local Directory Listings & Backlink Checklist

For RANLOCK Roofing & Construction LLC. This is a manual execution checklist —
there's no API/connector access in this environment to create these listings
directly, so each line below is something a human (owner or staff) submits
through that site's own form. Budget ~2-3 per week rather than all at once;
rankings move over months, not days, and a burst of identical new listings in
one day can read as spammy to some directories.

## 1. Canonical NAP (Name / Address / Phone) — copy exactly, every time

Inconsistent formatting across directories (abbreviating "Suite" as "Ste",
dropping the suite number, using a different phone format) actively hurts
local SEO. Use this exact block everywhere:

```
RANLOCK Roofing & Construction LLC
1322 Space Park Drive, Suite C113
Houston, TX 77058
(281) 299-1086
https://ranlock.com
```

Category/business type to select wherever a directory asks: **Roofing
Contractor** (primary), with Siding, Window Installation, Gutters, and
General Contractor as secondary categories where the platform allows more
than one.

Service area: list every city you already have a landing page for —
Houston, Baytown, Clear Lake, Cypress, Deer Park, Friendswood, League City,
Pasadena, Pearland, Spring, Sugar Land, Texas City, The Woodlands, Tomball,
Webster.

## 2. Directory listings — priority order

| # | Directory | Why it matters | Notes |
|---|---|---|---|
| 1 | Google Business Profile | Already flagged as highest-priority separately — do this first if not done | Free |
| 2 | Bing Places | Same idea as GBP, lower effort, still indexed | Free |
| 3 | Better Business Bureau (BBB) | High trust signal, strong domain authority backlink | Accreditation costs money; a free basic listing does not require it — don't claim "BBB Accredited" unless you actually pay for and complete accreditation |
| 4 | Yelp for Business | High consumer trust for home services | Claim existing listing if one already exists (often auto-created) rather than creating a duplicate |
| 5 | Angi (Angie's List) | Strong for roofing/home-services leads specifically | Paid lead-gen tiers exist — free basic profile is enough for the backlink/citation value |
| 6 | HomeAdvisor / Angi Leads | Same company as Angi now, check for a separate listing | Optional — paid lead model, decide separately from pure SEO value |
| 7 | Houzz | Good for before/after project photos, reaches renovation-intent searchers | Upload real project photos only |
| 8 | Nextdoor Business Page | Hyper-local, good for referral-driven neighborhoods (HOAs, subdivisions) | Free |
| 9 | Facebook Business Page | Not a directory per se, but counts as a citation + review surface | Keep NAP block identical here too |
| 10 | Thumbtack | Lead-gen + citation | Paid-per-lead, optional |
| 11 | Apple Business Connect | Powers Apple Maps / Siri results | Free, often overlooked |

Do not claim licenses, certifications, warranties, or "accredited" status on
any of these profiles unless it's actually true and current — several
directories (BBB especially) verify this and a false claim can get a listing
suspended.

## 3. Backlink targets (earned links, not directories)

These move domain authority more than directory citations do, but take
real outreach — no shortcut:

- **Local chambers of commerce** — Houston, Bay Area Houston (Clear Lake/
  Webster area), Pearland, League City, Sugar Land, The Woodlands. Chamber
  membership (usually $150-500/yr) typically comes with a member directory
  backlink from a high-authority local domain.
- **Manufacturer "find a contractor" pages** — RANLOCK currently holds:
  - **GAF Master Elite** — confirm RANLOCK's profile is live and current on GAF's own "Find a Contractor" directory (log into the GAF contractor portal to check/update the listing — don't guess the public URL, it's generated per-contractor by GAF). Master Elite status also qualifies RANLOCK to badge pages with the GAF Master Elite logo and reference GAF-backed extended warranties — use only GAF's current, approved logo/usage guidelines from the portal.
  - **Owens Corning Preferred/Platinum Contractor** (confirm exact current tier before publishing, since the badge and backlink differ by tier) — same approach: log into the Owens Corning contractor portal to confirm/update the public locator listing.
  - Do not add CertainTeed SELECT ShingleMaster or any other manufacturer program RANLOCK doesn't hold.
  - Confirm both certifications are current (not expired/lapsed) before publishing badges or backlink claims — these are typically renewed annually.
- **Local news / sponsorships** — sponsoring a Little League team, high
  school booster club, or local charity event often comes with a webpage
  mention + link; local news coverage of a community-visible project
  (storm response, a notable before/after) is a strong, naturally-earned link.
- **Industry associations** — National Association of the Remodeling
  Industry (NARI) Houston chapter, Greater Houston Builders Association —
  membership directories are backlink sources if RANLOCK joins.
- **Supplier/partner pages** — any roofing material supplier or distributor
  RANLOCK buys from regularly may list contractor customers/partners on
  their site; worth a direct ask.
- **Insurance/public-adjuster partners** — if RANLOCK already has referral
  relationships here (per the commercial-growth skill's target categories),
  ask if a mutual-partner page/link makes sense.

## 4. Suggested cadence

| Week | Action |
|---|---|
| 1 | Google Business Profile + Bing Places fully filled out (photos, hours, services, service area) |
| 2 | BBB basic listing + Yelp claim/clean-up |
| 3 | Angi + Houzz (with real project photos) |
| 4 | Nextdoor + Facebook Business Page NAP cleanup |
| 5-6 | Join 1-2 local chambers relevant to highest-volume service cities |
| Ongoing | One outreach email/week to a potential backlink source (supplier, association, local news) |

## 5. Tracking

Add a simple tracker (new tab in the existing prospect-tracking Sheet, or a
new one) with columns: `directory_name, url, date_submitted, status
(pending/live/rejected), login_email_used, notes`. This avoids duplicate
submissions and gives a quick audit trail of what's live.
